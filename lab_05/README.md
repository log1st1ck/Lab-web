# Лабораторна робота №5

Відкрийте `index.html`, щоб перейти до трьох завдань. Зображення вирізані зі зразків у методичці.

У другому завданні єдиний дочірній елемент `body` — це `img`. Псевдоелементи `::before` та `::after` належать `body`, оскільки `img` є заміщуваним елементом і браузери зазвичай не відображають його псевдоелементи.
