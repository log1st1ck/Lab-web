# Лабораторна робота №4

Відкрийте `index.html`, щоб перейти до картки SSD, дерева або галереї.

## Фото для генеалогічного дерева

У `tree/img/` є 15 квадратних JPG-заглушок. Щоб додати фото, замініть відповідний JPG, зберігши ім’я файлу. Роль підписана на відповідній сторінці в `tree/people/`. Наприклад, `father.jpg` є фото для сторінки «Тато». Гілки прадідів і прабабусь пронумеровані зліва направо на карті.
